# Weekend Planner

Weekend Planner is a simple web application that helps users decide what to do during the weekend. Based on the selected mood and budget, the app generates a random activity plan.

## Features

- Choose your mood:
  - Lazy
  - Active
  - Adventurous

- Select a budget:
  - Low
  - Medium
  - High

- Generate a random weekend plan

- View details including:
  - Destination
  - Activity
  - Reward
  - Risk
  - Budget level

- Generate a new plan anytime

## Installation and Usage

1. Clone the repository:

```bash
git clone https://github.com/your-username/weekend-planner.git
```

2. Navigate to the project folder:

```bash
cd weekend-planner
```

3. Open `index.html` in your web browser.

Alternatively, you can use the VS Code Live Server extension:

- Open the project in VS Code
- Right-click `index.html`
- Select **Open with Live Server**

## How It Works

1. Select a mood.
2. Choose a budget.
3. Click **Generate Plan**.
4. The application filters available plans and displays a random option matching your preferences.
